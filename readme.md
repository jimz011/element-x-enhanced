# Element X Enhanced

This is a heavily modified version of Element X to look and feel like Element Classic.

Features:
- Proper spaces access like in Classic
- Show last contacted person as avatars at the top like in Classic
- Filters for Unread, People, Rooms, Favorites and Invites, not exactly like Classic, but very Classic-ish
- Option to mark all messages as read
- HEIC/HEIF support (on some devices this requires the Matrix Media Repo)
- Split screen support for foldables, this is resizable
- Preview thumbnails of video's and GIFs when using bridges like Whatsapp, Signal, Discord etc
- Show a progress bar when uploading/processing media
- Probably other stuff I did not mention
